# 🫁 PneumoniaMNIST Classification using ResNet50

A deep learning project for classifying chest X-ray images into **Normal** and **Pneumonia** categories using a ResNet50-based convolutional neural network.

The project uses the PneumoniaMNIST dataset and demonstrates the complete workflow from data loading and preprocessing to model evaluation and prediction.

---

## 📌 Project Overview

Pneumonia is a respiratory infection that can produce visible abnormalities in chest X-rays.

The objective of this project is to train an image classification model that distinguishes between:

- Normal chest X-rays
- Pneumonia chest X-rays

This project is intended for machine learning experimentation and educational purposes.

> This model is not intended for clinical diagnosis or medical decision-making.

---

## 🧠 Model

The classifier is based on **ResNet50**, a deep convolutional neural network that uses residual connections.

Residual connections allow information to bypass groups of convolutional layers, helping deep networks train more effectively.

The classification pipeline includes:

- ResNet50 feature extraction
- Pooling
- Dense classification layers
- Binary classification output

---

## 📂 Dataset

The project uses **PneumoniaMNIST 128×128**.

The dataset is stored in NumPy `.npz` format.

Example:

```text
pneumoniamnist_128.npz
```

The dataset contains predefined:

- Training images
- Validation images
- Test images

Classes:

```text
0 → Normal
1 → Pneumonia
```

---

## 🖼 Image Format

Images are chest X-rays with a resolution of:

```text
128 × 128
```

The notebook includes visualization of sample X-ray images together with their labels.

---

## 🔄 Preprocessing

The preprocessing pipeline includes:

- Loading data from `.npz`
- Normalizing pixel values
- Preparing image dimensions
- Converting grayscale images when necessary
- Preparing labels for classification
- Creating TensorFlow-compatible datasets

## 📊 Model Evaluation

The model is evaluated on unseen test data using:

- Test Accuracy
- Test Loss
- ROC-AUC
- Confusion Matrix
- Classification Report
- ROC Curve

The test set is not used during model training.

This provides a better estimate of how the trained model performs on unseen images.

---

## 📈 ROC-AUC

ROC-AUC measures how effectively the model separates Normal and Pneumonia cases.

An ROC curve is generated by comparing:

```text
True Positive Rate
vs
False Positive Rate
```

---

## 🔍 Prediction

The notebook demonstrates prediction on individual X-ray images.

Example:


The exact value depends on the trained model and selected image.
